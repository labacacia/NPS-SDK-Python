# Security Policy

## Reporting

Use GitHub private vulnerability reporting: https://github.com/labacacia/NPS-SDK-Python/security/advisories/new. Do not open a public issue. Include the affected version, reproduction conditions, and impact, with secrets and unrelated data removed.

Only the latest maintained branch and latest pre-release are supported unless maintainers state otherwise.

## Scope

Treat decoded data, URLs, certificates, and files as untrusted. Never log keys or tokens. Review bounds, signature checks, dependencies, and publishing.
